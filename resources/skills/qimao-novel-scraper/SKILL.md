# 七猫扫榜 · 新书设定生成器

把「扫榜 → 挑标杆 → 拆前3章 → 出新书设定」全流程做成标准作业程序。产出的不是榜单搬运，而是**可落地的写作选题方案**。

## 一、目的与边界（重要）

- 这个技能服务的是**写作者的选题决策**：哪些题材好写、新书容易火、容易赚钱。
- 对标原则：**换皮不换骨**。保留标杆的"爽感骨架"（身份反差、金手指快速兑现、每章爽点+钩子、快速打脸），但世界观、主角身份、金手指机制、人物关系必须全部换掉，确保不构成抄袭。
- 产出新书设定前，**必须先给用户 2~3 种候选方向**，等用户选定后再生成最终完整文档。禁止直接只出一个方案。

## 二、数据来源（CharacterArc 内置自动抓取）

本应用内置了**七猫自动抓取器**（主进程隐藏 Chromium 通过阿里云 WAF 反爬），无需手动粘贴书单。

- 页面：应用内「七猫扫榜」页面
- 进入页面即自动抓取当前榜单（默认男频·新书榜）
- 可在页面切换「男频/女频」频道和「新书榜/热销榜/完结榜」榜单
- 点击「刷新」重新抓取最新数据

### 榜单 URL 规律（对齐参考 skill）

| 内容 | URL 模式 |
|------|---------|
| 男频新书榜·日榜 | `https://www.qimao.com/paihang/boy/new/date` |
| 女频新书榜·日榜 | `https://www.qimao.com/paihang/girl/new/date` |
| 通用榜单 | `https://www.qimao.com/paihang/{sex}/{type}/{date\|month}/`（sex: boy/girl；type: new/hot/finish） |
| 书籍详情页 | `https://www.qimao.com/shuku/{bookid}/` |
| 章节阅读页 | `https://www.qimao.com/shuku/{bookid}-{chapterid}/` |
| 阅读器入口 | `https://www.qimao.com/reader/index/{bookid}/` |

## 三、标准流程

### Step 1 扫榜（数据采集）

在「七猫扫榜」页面自动抓取榜单。每本书含字段：排名、书名、作者、大类、小类、字数、热度、状态(连载/完结)、简介、最近更新+时间、详情页链接。

### Step 2 分析榜单（情报提炼）

对 TOP 榜做 5 个维度的观察：
- **题材分布**：各大类占比（男频通常都市/玄幻主导）
- **核心套路**：身份反差 + 金手指 + 打脸公式的共性
- **字数窗口**：新书期热度窗口对应字数区间（七猫约 23-50 万字 / 2-3 个月）
- **更新频率**：上榜书是否当日更新（稳定日更是门槛）
- **标题模板**：简介是否用 `【卖点1+卖点2+卖点3】` 标签前缀

### Step 3 挑标杆（关键决策）

选择逻辑：
1. 选**热门且好写、变现强**的赛道
2. 在该赛道内选**排名最高、热度最猛**的一本
3. 优先选**标题本身就是钩子**的书
4. 记录选择理由（赛道占比 + 排名 + 热度 + 特色）

### Step 4 看简介

打开详情页 `/shuku/{bookid}/`，抓简介全文 + 标签。简介能告诉你：主题、卖点、金手指机制、人物关系。

### Step 5 抓前 3 章

1. 详情页找"开始阅读"按钮，点击后会**新标签页**打开阅读器 `/reader/index/{bookid}/`
2. 正文容器：`.chapter-detail-article`
3. 目录容器：`.book-catalog-list-content a` 取章节链接（格式 `/shuku/{bookid}-{chapterid}/`）
4. 依次抓第 1、2、3 章，每章等待 2~3 秒后抓全文

### Step 6 拆解（核心产出）

对照 checklist 逐项分析：
- **开局钩子**：第 1 句是否即高潮？
- **金手指兑现**：第几章兑现？爽点隔不隔夜？
- **每章结构**：每章是否有 1 个完整爽点 + 1 个章末钩子？
- **打脸节奏**：反派何时登场、多久被收拾？
- **设定为爽服务**：金手指规则是否只指向一个爽点？
- **文风**：短句密度、对话占比、笑点/反差梗。

### Step 7 产出候选设定（必须多选，用户拍板）

拆解完成后，**在对话中**先给出 2~3 种候选新书设定方向，每种包含：
- 题材/世界观一句话
- 一句话概念钩子
- 主角身份 + 核心反差
- 金手指机制（换一个，不抄标杆的）
- 女主/关键人物
- 前 3 章各章钩子简述

然后**明确询问用户选哪一种**，等用户答复后再进入 Step 8。

### Step 8 输出最终新书设定文档

用户选定后，生成完整设定文档（`新书设定-{书名}.md`），结构：
1. 一句话核心卖点
2. 书名（含备选 2~3 个，带标题钩子分析）
3. 主角设定（身份、性格、动机、核心反差）
4. 女主/重要配角
5. 反派与大线（埋好长期冲突）
6. 金手指机制（规则、成长曲线、爽点）
7. 世界观/场景
8. 前 3 章大纲（每章：钩子、爽点、章末悬念）
9. 对标对照表（哪些算同构方法论、哪些是合法差异化）
10. 写作执行提醒

## 四、可扩展

同一套流程可平移到其他平台（起点、番茄、晋江），只需替换：榜单 URL、页面选择器、输出目录。
